# 🌐 个人博客网站 | Personal Blog Website

一个使用纯 HTML5 + CSS3 构建的响应式个人博客网站，作为 **Web 前端开发** 课程作业项目。

## 📖 项目简介

本项目是一个展示个人信息、技能经历和摄影作品的静态博客网站。通过这个项目，我学习并实践了现代 Web 前端开发的核心技术，包括语义化 HTML、CSS 布局（Grid、Flexbox）、响应式设计等。

## ✨ 功能特性

- **首页**：个人简介、最新动态时间线
- **关于我**：竞赛经历、兴趣爱好、旅行足迹展示
- **我的简历**：教育背景、实习经历、竞赛荣誉、联系表单
- **摄影作品**：旅行摄影作品画廊展示

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| HTML5 | 语义化标签、表单元素 |
| CSS3 | Grid 布局、Flexbox、CSS 变量、过渡动画 |
| 响应式设计 | 媒体查询适配移动端 |
| GitHub Pages | 静态网站托管 |

## 🎨 CSS 技术亮点

- **CSS Grid**：用于卡片网格、照片画廊、信息展示等响应式布局
- **Flexbox**：用于导航栏、表单元素的灵活排列
- **CSS 变量**：统一管理主题颜色、阴影、过渡效果
- **伪元素**：实现时间线装饰效果
- **媒体查询**：适配不同屏幕尺寸的响应式设计
